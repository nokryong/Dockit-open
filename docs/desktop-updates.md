# 앱 업데이트

배포 앱은 시작 3초 후와 이후 6시간마다 `nokryong/Dockit-open`의 새 릴리즈를 확인합니다. 새 버전이 있으면 sud-ui Modal에서 설치 여부를 선택합니다. 취소한 버전은 해당 실행 중 다시 안내하지 않습니다.

설치를 누르면 다운로드 진행률을 표시합니다. 다운로드가 끝나면 진행 중인 AI 작업을 기다린 후 열린 문서와 로컬 설정을 저장하고 설치·재시작합니다. 저장 실패나 응답 시간 초과 시 설치하지 않고 재시도를 제공합니다. 일반 종료 시 자동 설치는 꺼져 있습니다.

## UI 확인

`npm run dev`로 실행한 앱에서 `Ctrl+Shift+U` (macOS: `Cmd+Shift+U`)를 누르면 같은 모달을 미리 볼 수 있습니다. 설치를 누르면 진행률 → 저장 → 재시작 안내를 재현하고 닫힙니다. 이 미리보기는 파일 저장, 다운로드, 설치, 앱 종료를 실행하지 않습니다. 단축키를 다시 누르면 처음부터 볼 수 있습니다.

모달: `app/LIB/components/updates/AppUpdateModal.js`

## 배포 준비

`npm run package:desktop`은 현재 OS의 설치 파일과 업데이트 메타데이터를 `release/`에 만듭니다. `--publish never`로 업로드하지 않습니다. Windows는 NSIS, macOS는 DMG와 ZIP, Linux는 AppImage입니다. 소스·개인 데이터 전체를 패키지에 넣지 않도록 포함할 파일을 `electron-builder.yml`에 지정했습니다.

실제 배포 시에는 공개 GitHub 릴리즈에 해당 OS/아키텍처의 설치 파일, 블록맵과 `latest*.yml`을 함께 올려야 합니다. 버전은 `package.json`에서 올립니다. macOS 자동 업데이트는 서명된 앱이 필요하며, Windows도 배포 서명을 준비해야 합니다. 업데이트 저장소용 토큰을 앱에 넣지 않습니다.

배포 전 각 OS에서 설치한 앱으로 문서 저장 후 업데이트·재시작까지 확인합니다.
